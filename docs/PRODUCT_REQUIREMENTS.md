# HD2 战术配装终端 v0.1 产品需求基线

最后确认：2026-08-14

本文记录已经确认的产品范围。若用户后续提出新要求，以最新明确指令为准，并同步更新本文和 `DEVELOPMENT_STATUS.md`。

## 产品定位

- 免费、公开、非商业的 Windows 10/11 x64 桌面工具。
- 公开仓库：`I-am-blue/hd2-loadout-terminal`。
- 技术栈：Tauri 2、React、TypeScript、Vite。
- 源代码采用 MIT 许可证；游戏事实、评分数据和第三方素材另行声明权利边界。
- 面向中文玩家，界面为简体中文，装备显示中英文名称并支持别名搜索。
- About 页面声明“非官方粉丝工具，与 Sony、Arrowhead 无关联”，不使用官方标志。

## v0.1 范围

包含：

- 单人配装的引导选择和场景化规则评分。
- 本地收藏、分享码、装备解锁过滤。
- 一次性、非聊天式 BYOK AI 战术报告。
- 离线核心、签名数据更新、用户确认的应用更新和主动日志导出。

不包含：

- 小队分析。
- 账号或云同步。
- 游戏进程读取或悬浮窗。
- 实时银河战争。
- 社区投票或聊天式 AI。
- 头盔与披风。

## 配装与装备库

完整配装包含：

- 1 件护甲。
- 1 把主武器。
- 1 把副武器。
- 1 个手雷。
- 4 个不可重复的战备。
- 1 个被动。

战备分类固定为：

- 轨道战备。
- 飞鹰战备。
- 蓝色战备：支援武器、背包、载具和机甲。
- 绿色战备：炮台和防御工事。

装备面板支持中英文名称、别名、类别、定位和“仅显示已解锁”。装备库配置可选。武器详情从装备库的“详情”按钮打开右侧栏，上部展示武器视觉区域，下部展示人工核验的 Wiki 参数、获取方式、来源和游戏版本；无法核验时显示“资料待核验”。

战备和被动只有在取得明确再分发授权后才使用 Wiki/游戏原图；未确认时使用通用占位图形。

## 评估体验

主界面顶部选择敌方阵营、难度和具体任务。配装未完整时展示实时能力覆盖和缺口，不生成总分。完整后展示：

- 100 分场景适配总分。
- 八维雷达图：清杂、中甲处理、反重甲、单体爆发、控场、生存与机动、持续作战、任务与支援。
- 关键缺口、重复定位、协同效果和计算明细。
- 两条本地规则选出的单槽替换路线，以及替换前后分数。

场景权重由阵营基准、难度增量和任务增量相加后归一化，玩家不能自行修改。

## 评分规则

- 每件装备在八个维度维护 0–25 的基础贡献、定位、上下文修正、协同和冲突规则。
- 阵营/任务上下文修正范围为 0.5–1.5。
- 同维度贡献由高到低采用 `100%、100%、60%、60%、35%……` 的递减权重。
- 每维协同与冲突修正合计限制在 `-10～+10`。
- 每维最终分限制在 0–100。
- 总分是八维分数按场景权重计算的加权平均。

关键缺口封顶：

- 难度 1–3：不封顶。
- 难度 4–6：关键维度低于 25 时最高 79；低于 15 时最高 69。
- 难度 7–10：关键维度低于 35 时最高 69；低于 20 时最高 59。
- 关键维度由阵营和任务数据声明，界面展示触发原因。

## 收藏与分享码

- 收藏只保存在本机。
- 分享码包含配装、场景、标题、数据版本和格式版本，不包含 API Key 或个人信息。
- 格式固定为 `HD2T1.<base64url(deflate-json)>.<crc32>`。
- 导入时限制解码结果不超过 16KB，并校验格式版本、校验和、槽位合法性及装备 ID。

## AI 报告

- 设置项包括 HTTPS 服务地址、模型名和 API Key；只额外允许 localhost HTTP。
- 调用 OpenAI 兼容 Chat Completions 接口，30 秒超时，可取消，低随机度。
- 对响应执行结构化校验。
- `AiReport` 只含摘要、优势、风险和两条替换路线说明，不返回或覆盖任何分数。
- 相同配装、场景、数据版本和模型的报告在本机缓存；用户可主动重新生成。
- 无配置、断网、超时或响应异常不影响本地评分。

## 本地数据与更新

- 首发目标是覆盖发布时全部战斗相关护甲、武器、手雷、战备、被动、阵营、难度和任务。
- 事实来源在维护阶段人工交叉核对，运行时不依赖第三方 API。
- 在线数据由 GitHub Releases 发布签名清单和版本化数据包。
- 启动后每 24 小时最多检查一次。
- 更新必须验证 Ed25519 签名、SHA-256、模式版本和最低 App 版本，然后原子替换并保留上一有效版本。
- 程序更新使用 Tauri 签名更新包，自动检查后提示用户确认，不静默安装。
- v0.1 可提供未做 Windows 代码签名的 NSIS 测试安装包，并在发布说明提示 SmartScreen 警告。

## 界面与可访问性

- 原创深色战术终端风格，不复刻官方 UI。
- 页面包括配装评估、我的收藏、装备库、设置/关于。
- 页面可以使用滚轮纵向滚动。
- 支持五档字体大小；“中”为默认大小。
- 竖排槽位文字必须保持正常阅读方向。
- 支持键盘操作、可见焦点和非纯颜色状态提示。
- 窗口从 1280×720 起可缩放。

## 验收与测试

- 单元测试覆盖评分确定性、递减贡献、上下文权重、协同边界、全部封顶规则和八维上下限。
- 为各阵营、难度层级和典型任务建立黄金配装夹具。
- 覆盖分享码往返、损坏校验和、未知装备、旧版本迁移、超长输入和非法槽位组合。
- 覆盖双语搜索、装备库过滤、收藏、替换建议、键盘导航、离线启动和窗口缩放。
- 覆盖数据包签名失败、下载中断、模式不兼容、原子替换失败和上一版本回滚。
- 覆盖 AI 超时、取消、非 JSON、越权改分、未知替换候选和自定义端点错误。
- 确认 API Key 不出现在本地文件、日志、导出内容、分享码或网络错误提示中。
- GitHub Actions 在 Windows x64 上运行类型检查、单元测试、目录模式校验、黄金夹具和 Tauri 构建检查。
- 普通设备上的完整配装本地评分目标低于 100ms。
- 断网时除更新和 AI 外全部功能可用。
- 数据损坏能自动回退，分享码能稳定还原，无遥测。
